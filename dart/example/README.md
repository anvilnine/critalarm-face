# critalarm_face example

A Flutter app that shows what the [critalarm_face](../README.md) package can do. It has four tabs:

- **Faces**: every face state, with its label.
- **Blend**: pick two faces and slide between them.
- **Idle**: the idle face.
- **Ringing**: every ringing style, plus the shuffle.

Run it from this folder:

```sh
fvm flutter pub get
fvm flutter run -d chrome
```

The root [README](../../README.md) covers both packages in this repo.
