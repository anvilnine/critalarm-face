# critalarm-face

Crit, the [Crit Alarm](https://critalarm.app) mascot, as a reusable face system.

- `dart/`: the Flutter package `critalarm_face`. 36 expressions, blending, an idle loop and 18 ringing animations.
- `spec/`: `faces.json` and `fixtures/`, generated from the Dart package, plus `SPEC.md`, which explains every field so other languages can draw the same face.
